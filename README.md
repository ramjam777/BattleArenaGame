# Battle Arena Game

A text-based C# console game where the player chooses a character and battles a series of enemies.

## Features

- Warrior and Mage character classes
- Normal attacks and special abilities
- Health potion system
- Multiple enemies with increasing difficulty
- Hard Mode after completing the game
- Final game summary
- Input validation and exception handling

## Concepts Demonstrated

- C# fundamentals
- Methods
- Classes and objects
- Inheritance
- Abstract classes
- Interfaces
- Polymorphism
- Collections (List and Dictionary)
- LINQ
- Exception handling

## Requirements

- .NET SDK
- Visual Studio or Visual Studio Code

## Running the Project

1. Open the solution in Visual Studio.
2. Build the project.
3. Run the application.

## How the Game Works

The player enters a name and chooses either a Warrior or Mage. The player battles five enemies one by one using normal attacks, special abilities, and health potions.
After defeating all enemies, a game summary is displayed. Completing Normal Mode unlocks Hard Mode, where enemies become stronger, character abilities are more limited, and health potion quantity is increased.
This demands more strategy from the player, making it more challenging!
